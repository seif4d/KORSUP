# KORSUP® — Ultimate Skills Pack

صفحة بيع تفاعلية متجاوبة، مكتوبة باستخدام HTML + CSS + JavaScript من غير Framework أو باك إند.

## تشغيل الصفحة
افتح `index.html` في المتصفح، أو ارفع **الثلاثة ملفات** (`index.html`, `styles.css`, `script.js`) في نفس المجلد على Netlify أو GitHub Pages.

كمان فيه ملف `KORSUP_Landing_Page.html` مستقل خارج ZIP، بيحتوي HTML/CSS/JS كلها في ملف واحد ويمكن فتحه مباشرة.

## التعديلات المطلوبة قبل النشر
1. افتح `script.js`، وعدّل `CONFIG.checkoutUrl` إلى رابط دفع حقيقي، **أو** `CONFIG.whatsapp` إلى رقم المشروع بكود البلد من غير `+`، مثال: `2010XXXXXXXX`.
2. عدّل `CONFIG.price` لو السعر النهائي اختلف عن 499 جنيه. السعر بيتحدث تلقائيًا في الصفحة وأزرار الطلب.
3. أكد سياسة مدة الوصول، التسليم، المرتجعات، وأسئلة FAQ قبل تشغيل الشراء.
4. راجع فهرس المحتوى النهائي وفيديوهات المعاينة قبل النشر. العدّاد 8,909 يشير إلى **ملفات** وليس كورسات مستقلة، بناءً على ملف الفهرس المرفق.
5. اربط إحصائيات Google/Meta فقط عند الحاجة وبما يتوافق مع سياسة الخصوصية والإفصاح للمستخدم.
6. تحقق من توافر الاسم والحسابات والنطاق قبل اعتماد البراند التجاري.

## التفاعلات المفعلة
- اختيار 6 مجالات مع تحديث لوحة المعاينة فورًا.
- قائمة موبايل قابلة للفتح والغلق.
- مودال طلب قابل لربط واتساب أو رابط دفع (يظهر كنسخة تجريبية دون ربط).
- أقسام FAQ مفتوحة/مغلقة، حركة خفيفة، شريط تقدم التصفح، ومراعاة تقليل الحركة.

## المحتوى والمصدر
المجالات وأعداد الملفات مستخرجة من ملف فهرس `00_Unvirsty_404_Index.html` الذي قدمه صاحب المشروع. بعض الملفات أصلًا صوتيات وملفات مساعدة، وبعض الدروس بلغات متنوعة؛ لم يتم الادعاء بأنها كورسات مستقلة أو بشهادات رسمية أو توظيف.
