# KORSUP Public Store — Final V5

دي نسخة الصفحة العامة فقط، جاهزة للرفع كـ Static Site على GitHub Pages أو أي استضافة ملفات.

## الجديد
- شعار KORSUP الكامل من الهوية السابقة `assets/korsup-logo-transparent.png`، مع ملفات الأيقونات والـfavicon الأصلية التي أرسلتها.
- أيقونات إنستجرام وفيسبوك وتليجرام وواتساب في هيدر الموقع، مع قسم تواصل مستقل وواضح.
- حسابات تليجرام الإضافية ضمن قسم التواصل.
- حذف رابط «دخول الأعضاء» بالكامل من الصفحة العامة.
- استخدام أيقونات المجالات الستة الأصلية بدل الرموز النصية.
- الفهرس التجريبي `catalog/` مازال عامًا بلا روابط Google Drive.
- فيديوهات المعاينة الخمسة من الملفات الحقيقية، تشتغل من نافذة معاينة.
- الطلب على واتساب يدوي بعد التحويل، **وليس** دفعًا آليًا أو طلبًا محفوظًا على السيرفر.

## النشر
ارفع **محتويات** المجلد (مش المجلد نفسه) إلى جذر الموقع أو المستودع، وتأكد إن `index.html` و`assets/` و`catalog/` في نفس المستوى.
